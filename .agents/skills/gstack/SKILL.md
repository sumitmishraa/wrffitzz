# gstack: Software Engineering Team Methodology

gstack turns AI coding sessions into a multi-disciplinary software factory:
- **CEO / Founder Review**: Challenge premises, define the 10-star product experience, cut unnecessary scope, focus on the single sharpest wedge.
- **Design Review (Anti-Slop)**: Ruthlessly eliminate generic AI aesthetics. Enforce custom curated color palettes, bespoke typography pairings (never browser defaults), micro-interactions, responsive hierarchy, and editorial layout standards.
- **Engineering Review**: Lock down clean component architecture, verify React hook dependencies and state management, ensure responsive performance, and handle edge cases gracefully.
- **QA Lead**: Verify user flows in the real browser, reproduce and fix bugs, and ensure zero regression across shopping cart, pin verification, and checkout.
- **Release Engineer**: Clean code diffs, maintainable structure, and verified deliverables.

## Core Rules & Principles
1. **Never Ship AI Slop**: Every UI element must feel intentionally crafted, premium, and aligned with modern design standards (inspired by editorial luxury streetwear, Dribbble, Keithston, 21step).
2. **Iron Law of Root Cause**: Never apply a band-aid fix without understanding the underlying error and tracing data flow.
3. **Verified Execution**: Always verify changes in the live dev environment before claiming completion.
